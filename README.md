# 邊際成本法損益表 · 排位練習

一個畀學生練習編製**邊際成本法（變動成本法）損益表**嘅互動網站。
題目會列出一堆項目（**名稱**同**金額**分開），學生要將佢哋拖返入損益表每一行嘅正確格（名稱欄／內欄金額／外欄金額），然後即時批改。

## 點樣開啟

1. 直接雙擊 `index.html`（用 Chrome / Edge 打開就得，唔需要伺服器、唔需要安裝任何嘢）
2. 或者喺呢個資料夾執行：
   ```
   python -m http.server 8766
   ```
   然後瀏覽 `http://127.0.0.1:8766/index.html`

## 玩法 / 功能

損益表每一行有三個可放置嘅格：**項目名稱**、**內欄金額**、**外欄金額**。
項目區分開兩堆俾學生拖：`項目名稱`（例如「直接原料成本 ($5.3 × 43 500)」）同 `金額`（例如「230 550」）。

| 功能 | 說明 |
|---|---|
| 拖曳放置 | 名稱拖去描述欄、金額拖去對應嘅金額欄；電腦用滑鼠拖，iPad／手機就**長按約半秒**等項目浮起再拖（手指掂到頂／底邊會自動捲頁），短撳就係選取 |
| 點擊放置 | 撳一下項目 → 再撳目標格（鍵盤 Enter/Space 同樣有效） |
| 金額分欄 | 金額必須放喺啱嘅欄（變動成本放內欄、固定成本／銷貨／邊際貢獻／淨利放外欄），而且要同同行名稱配對；變動成本總額 1 187 550 都要拉去最後一項變動成本旁邊嘅外欄 |
| 變動成本可互換 | 「減：變動成本」下面各行位置可以自由調換，只要全部喺呢一節入面就算啱 |
| 固定成本可互換 | 「減：固定成本」下面各行位置可以自由調換，只要全部喺呢一節入面就算啱 |
| 同名項目 | 第三題有兩個「生產間接成本」（變動／固定），項目區會用小標籤分辨，報表入面只顯示名稱 |
| 對調位置 | 將已放入嘅項目拖去另一個已佔用嘅格，兩者會自動對調 |
| 放返項目區 | 撳項目右邊嘅 `↩` 鈕，將佢攞走 |
| 題目表格成本性質 | 題目資料表最右加「成本性質」欄，成本行撳「變動／固定」二揀一（再撳取消），非成本行顯示 —；檢查答案會計分，列印會印出揀咗嘅結果 |
| 檢查答案 | 答啱顯示綠色 ✓，答錯顯示紅色 ✗ 並抖動提示；滿分視題目而定（每行名稱＋金額各 1 分，另加總額，再加題目表格每行成本性質 1 分），會記錄嘗試次數同上次成績；撳檢查嗰陣先會顯示每項嘅計算式 |
| 顯示答案 | 教師專用：撳掣後要輸入密碼（預設 `2897`，喺 `app.js` 頂部 `TEACHER_PW` 改）先會顯示標準答案 |
| 重設 | 清空並重新洗牌項目 |
| 題目切換 | 題目卡頂有「第一／二／三／四題」按鈕，轉題會自動重設（項目洗牌、嘗試次數歸零） |
| 格式表練習 | 第五個掣「格式表 · 練習」：空白損益表共 11 格，學生將右邊「格式列」（用第一題子怡公司真實項目名做例子：銷貨／減：變動成本／直接原料・直接人工・變動生產間接・變動銷售／邊際貢獻／減：固定成本／固定生產間接・固定銷售／淨利）拖入正確位置砌出格式；砌好嘅格式同真報表一樣（$欄、底線、雙線），但唔需要數字及列式；撳／拖／對調／↩攞走同檢查答案、顯示答案（同一個教師密碼）、重設、列印全部適用，同類明細行可互換 |
| 列印 / PDF | 印出題目（含揀好嘅成本性質）＋損益表（隱藏項目區同按鈕），可以存做 PDF 交功課 |

## 點樣換另一條題目

全部題目資料都喺 `app.js` 頂部嘅 `QUESTIONS` 陣列入面（每題一個物件，現有第一至四題，照格式加多個就有多一題），改完儲存再重整頁面就得。

```js
const QUESTIONS = [ {   // 第一題（第二題照抄多一個物件）
  company: '子怡公司',                 // 公司名
  title: '損益表',                     // 報表名
  period: '截至 2023 年度 12 月 31 日止年度',
  brief: [ '第一段題目文字', '…',      // 題目內容（每段一行）
           { table: { caption: '表標題', head: ['欄一', '欄二'],
                       rows: [['…', '…']] } },   // { table } 可插入資料表（成本唔好預先分變動／固定）
           { list: ['第一點', '…'], start: 2, marker: 'i' } ],
                                         // { list } 插入 (i)(ii)…清單；start 續編號，marker:'a' 用 (a)(b)

  items: {                             // 項目（名稱同金額分開俾學生拖）
    mat: {
      label: '直接原料成本',           // 名稱
      formula: '($5.3 × 43 500)',      // 計算式（唔要就寫 ''）
      amount: '230 550',               // 金額（用空格分隔千位，跟足會計格式）
      col: 'inner',                    // 金額要放邊欄：'inner' 內欄 / 'outer' 外欄
      group: 'var'                     // 可選：分組名，同組項目喺同一節內位置可互換
    },
    vtotal: {
      label: '變動成本總額',           // 淨金額項目：淨係出現在金額區，冇名稱 BAR
      amount: '1 187 550',
      col: 'outer',
      amtOnly: true   // 淨係出現在金額區（例如總額數字），唔會有名稱 BAR
    },
    // ……
  },

  layout: [                            // 損益表由上至下每一行
    { t:'bar',     id:'sales' },       // 有得擺嘢嘅空位
    { t:'section', label:'減：變動成本' },  // 固定小節標題
    { t:'bar',     id:'mat', group:'var' },         // 有 group：同組任何項目放邊行都得
    { t:'bar',     id:'voh', group:'var' },   // 金額下面加一條線就加 underline:true（小計）
    { t:'bar',     id:'vsell', group:'var', underline:true, outerExpect:'vtotal' },  // 外欄要擺總額金額（學生要拉過去）
    { t:'total',   label:'變動成本總額', amount:'1 187 550', underline:true },  // 獨立總額列（唔用可以刪走）
    { t:'bar',     id:'cm' },                        // 結果列（必須係指定項目）
    { t:'bar',     id:'np', double:true },           // 雙線（淨利）
    // ……
  ]
} ];   // ← 第二題照上面成個物件抄多一份
```

改題目時記得：

- `items` 裡面每個 `id` 都要喺 `layout` 出現一次，否則項目會漏咗或者擺唔到落去。
- 項目同 `layout` 行寫上同一個 `group`（`'var'` 變動／`'fix'` 固定），嗰行就變成「同組任何項目都可以」，即係同一節入面位置可以互換；冇寫 `group` 嘅行就必須放指定項目。
- 兩個項目名稱相同（例如第三題兩個「生產間接成本」），喺其中加 `tag: '變動'`／`tag: '固定'`，項目區名稱旁會顯示小標籤分辨（報表入面唔顯示）；金額 BAR 一律唔顯示標籤，金額相同（例如兩個 342 600）唔使處理，批改認數值，邊個擺邊格都得。
- 題目表格成本性質答案喺每題 `brief` 入面 `{ table: { nature: [...] } }` 設定，同 `rows` 一一對應：`'var'` 變動／`'fix'` 固定／`null` 唔使揀（例如產量、銷量、售價）。要改答案淨係改呢個陣列；要成個表唔使揀就刪走 `nature` 呢行。
- 格式表練習嘅標準順序喺 `app.js` 嘅 `FMT_EXPECTED`（預設 11 格：銷貨 → 減：變動成本 → 變動明細×4 → 邊際貢獻 → 減：固定成本 → 固定明細×2 → 淨利），右邊格式列喺 `FMT_BLOCKS`；要改格數／標籤就改呢兩個。
- 批改規則：名稱要喺啱嘅行（或者同組行入面），金額要放喺該項目指定嘅欄（`col`），而且要同同行嘅名稱配對；外欄總額（`outerExpect`）獨立計分；題目表格每行成本性質獨立計 1 分。滿分 = 可放嘅行數 × 2 ＋ 總額數 ＋ 成本性質題數。
